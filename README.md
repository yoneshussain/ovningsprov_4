# Övningsprov 4 – U04 JavaScript

Skapat utifrån kursmålen och provinformationen som du delade. Detta är ett träningsprov, inte lärarens riktiga prov.

## Del 1 – Quizträning
Öppna `quiz.html`. Det innehåller 18 flervalsfrågor om:
- Promises, async/await, call stack och event loop
- Node.js, npm, package.json och Vite
- Linting och formattering
- Funktionell och objektorienterad programmering

Quizet rättar svaren och visar förklaringar efter inlämning.

## Kom igång
1. Packa upp ZIP-filen.
2. Öppna mappen i VS Code.
3. Starta `index.html` via Live Server.
4. Välj fråga och klicka på "Ladda fråga".
5. Skriv lösningen i motsvarande `questionN.js`.
6. Ladda frågan igen för att testa. Öppna Console för console.log().

## Fråga 10
`question10.js` importerar funktioner från `utils.js`. Båda filerna ligger i samma mapp. Kör via Live Server så att ES-moduler fungerar.

## Provträning
Försök göra praktiska delen på cirka tre timmar och utan att titta på lösningar. Gör quizet separat. Träna också på att förklara varför du väljer en viss arraymetod eller programmeringsstil.
