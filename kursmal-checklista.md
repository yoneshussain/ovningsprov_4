# Kursmål – checklista inför provet

## Asynkron JavaScript
- [ ] Förklara vad en Promise representerar.
- [ ] Känna igen pending, fulfilled och rejected.
- [ ] Förklara vad async gör med funktionens returvärde.
- [ ] Förklara vad await pausar – och vad det inte pausar.
- [ ] Förklara call stack, microtasks och timer callbacks.
- [ ] Använda fetch, response.ok, response.json och try/catch.

## Verktygskedjan
- [ ] Förklara vad Node.js är.
- [ ] Förklara vad npm används till.
- [ ] Känna igen package.json, dependencies och scripts.
- [ ] Förklara vad Vite gör.
- [ ] Förklara skillnaden mellan linting och formattering.

## Programmeringsparadigm
- [ ] Förklara funktionell programmering och rena funktioner.
- [ ] Förklara immutability och varför det kan vara användbart.
- [ ] Förklara objektorienterad programmering.
- [ ] Förklara constructor, metod och getter.
- [ ] Ge exempel på när funktionell respektive objektorienterad kod passar.

## Praktiska färdigheter
- [ ] Skriva funktioner och arrow functions med villkor.
- [ ] Välja mellan map, filter, find och reduce.
- [ ] Använda spread och rest med arrayer och objekt.
- [ ] Skapa DOM-element och event listeners.
- [ ] Skapa och använda klasser.
- [ ] Importera och exportera funktioner mellan ES-moduler.
